# P05 Exchange Contract v0.1 — Working Proposal

These artifacts are a **draft** previously prepared for P05 architecture discussion, **not an approved contract or a running API**:

- `openapi.yaml` — proposed OpenAPI 3.1 service interface.
- `schemas/analysis-result.schema.json` — proposed structured analysis output.
- `examples/analysis-result.json` — synthetic example result for schema discussion.

Before treating this as an integration commitment, review all field semantics, errors, validation, publication workflow, backward compatibility, consumer needs and authorization with the group (including P06, P20, P17 and P21). Numeric examples are illustrative only. Do not expose draft endpoints as verified implementation.
